Concurrent AI coding-agent delivery · read-only

See what every agent
is doing right now.

Threadbeam turns a closed, validated stream of lifecycle events into one live view of what each agent is working on, what's blocked, what needs an answer, and what's landed — across as many concurrent repos as you're tracking. It never reads transcripts, prompts, source, or diffs, and it can never launch, steer, or stop an agent. Just node server.mjs.

What it shows you

Every provider, one table

Codex, Claude, Mistral, Ollama, and Luna side by side — sortable by state, project, or activity, colour-coded so a glance tells you who's doing what.

Blockers and questions, up front

A blocked task surfaces its cause, owner, and next action — not just a red badge buried in a table row.

Per-project rollups

Tracking several repos through one instance? The same four counts the summary shows, broken down by project.

Delivery metrics

Completions and average time-to-complete per provider, and average time-to-resolve for blockers — derived from the same event log, nothing new to configure.

Notifications, opt-in

A browser notification the moment a task is genuinely newly blocked or asks a question — never on page load, never repeated for the same still-open item.

Zero dependencies, one binary of a container

Node.js 22 built-ins only. A strict stdin-only event emitter, an owner-private JSONL store, and a hardened, read-only container — no login, no write endpoint, no GitHub access.

The whole dashboard

Quickstart

$ node server.mjs
$ open http://127.0.0.1:4317

$ echo '{"schemaVersion":1,"provider":"claude","repo":"example/project","project":"example-project","taskId":"issue-42","state":"implementing","model":"claude-sonnet-5","branch":"agent/issue-42","worktree":"issue-42","timestamp":"2026-08-02T00:00:00Z"}' \
    | node bin/emit.mjs

No dependency installation, no login, loopback by default. See the README for the container quickstart, the full event contract, and docs/adapters.md for wiring up a bounded-task wrapper automatically.
